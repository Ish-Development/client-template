# Layout

Fictional sample brand. Values: tokens.json (space, radius).

## Hard rules
```yaml
- rule: Do not center every block
  why: Centered text everywhere removes the reading line and slows people down.
  where: Website, email
- rule: Do not use more than one accent color in a component
  why: Two accents compete and neither reads as the action.
  where: Buttons, cards, banners
```
