# Color

Fictional sample brand. Values: tokens.json (color).

## Hard rules
```yaml
- rule: Do not use sea as a full-bleed background on long text pages
  why: Long reading on a saturated ground tires the eyes, the opposite of the product.
  where: Articles, help pages, product details
- rule: Alert color is only for errors and returns, not decoration
  why: If it decorates, people stop noticing it when it matters.
  where: Forms, checkout, returns
```
