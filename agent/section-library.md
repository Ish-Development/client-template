# Section library

Studio method. Every section is built for one main job. Some do a second job.
The library is examples. Which sections a client gets is settled in the workshop.
The menu bar and the footer come with every site. They are not counted.

Components live in Figma (source of truth) and are built in Webflow or Astro.
Fill the links per client. This file points to components. It does not copy them.
