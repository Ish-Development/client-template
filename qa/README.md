# QA

Design critiques and internal QA reports (design-qa skill).
- qa/YYYY-MM-DD-figma-<page>.md: Figma critique, small fixes, design questions
- qa/YYYY-MM-DD-webflow.md: Webflow QA, read-only, ranked issues
- qa/YYYY-MM-DD-kit-test.md: kit test report (kit-test skill). The fresh agent's outputs sit
  next to it as qa/YYYY-MM-DD-kit-test-<task>.md or .html. Probes, never client work.
Screenshots go in qa/screenshots/.
